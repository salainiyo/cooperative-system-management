# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-11-22

### Added

- Initial public release.
- Member savings, loans with declining-balance interest, repayments and
  waterfall allocation from a transaction ledger.
- Admin console and member self-service portal.
- Full CI/CD: backend and frontend tests, Docker image publishing and a
  Terraform plan gate.
- Terraform + Ansible provisioning and Prometheus monitoring for the demo VM.
- Contribution guide, security policy and issue/PR templates.
